Пояснення вибору типів даних у таблиці

1. Стовпець id — INTEGER
Тип INTEGER обрано для зберігання цілого числового ідентифікатора кожної книги. Він дає змогу однозначно розрізняти записи. Обмеження PRIMARY KEY забезпечує унікальність ідентифікаторів, а SQLite автоматично присвоює значення цьому стовпцю, якщо його не вказати під час додавання запису.
2. Стовпець title — TEXT
Тип TEXT використовується для зберігання назв книг, оскільки вони складаються з літер, слів, пробілів та інших символів. Числові типи для цього стовпця не підходять, адже назви потрібно зберігати як текстові рядки. Обмеження NOT NULL забороняє створювати записи без назви книги.
3. Стовпець author — TEXT
Тип TEXT обрано для зберігання імен і прізвищ авторів. Ці значення є текстовими, а не числовими, тому їх не потрібно використовувати в арифметичних обчисленнях. Обмеження NOT NULL гарантує, що в кожного запису буде вказано автора.
4. Стовпець year — INTEGER
Тип INTEGER підходить для року видання книги, оскільки рік є цілим числом. Це дозволяє сортувати книги за роком видання, порівнювати роки та виконувати числові умови в запитах.
5. Стовпець price — REAL
Тип REAL обрано для ціни книги, оскільки вона може містити дробову частину, наприклад 250.50 або 210.75. Це дозволяє зберігати та порівнювати ціни й виконувати арифметичні операції.
6. Стовпець quantity — INTEGER
Тип INTEGER використовується для зберігання кількості примірників кожної книги. Кількість книг у цьому прикладі є цілим числом, оскільки примірники рахують поштучно.
