1. Чому WHERE price = NULL повертає порожній результат?
SQL не порівнює NULL як звичайне значення. Вираз price = NULL дає невизначений результат, а WHERE залишає лише рядки, для яких умова істинна.


2. Чим WHERE відрізняється від HAVING?
WHERE фільтрує окремі рядки таблиці до групування.

HAVING фільтрує групи після GROUP BY, часто за результатами агрегатних функцій, наприклад COUNT() або AVG().

3. Коли варто уникати SELECT * і чому?
SELECT * краще уникати, коли потрібні лише окремі стовпці. Явний перелік стовпців робить запит зрозумілішим, зменшує обсяг зайвих даних і допомагає уникнути несподіваних змін результату, якщо структура таблиці зміниться.
